# Process Flow component

Focused React/Vite extraction of the “Explore. Generate. Refine. Scale.” section from `craft.wild.as`.

The reusable component lives at `src/components/ProcessFlowSection.jsx`. It includes the responsive layout, local Sneak fonts, animated double helix, pointer displacement, active-stage emphasis, and tracked pixel underline.

```sh
npm install
npm run dev
```

See `REVERSE_ENGINEERING.md` for the source DOM, CSS, measurements, behavior, and component boundary.
