# "Observed in 277 apps" — 15s ad

**Logline:** every product team argues about the same flows from memory. Vitrines
has the receipts.

**Format:** 15s. Master in 9:16 (paid social), cut 1:1 and 16:9 from the same
timeline. Silent-first — all copy is burned in, VO optional.

**One rule:** no video model ever renders Vitrines UI, product screenshots, or
any legible text. Those are real captures, generated by
[`scripts/generate-ad-assets.ts`](../scripts/generate-ad-assets.ts). Higgsfield
only makes shots where nothing has to be readable. A model that garbles a
screenshot destroys the exact claim the ad is making.

## Higgsfield prompts

Only two shots. Both are deliberately human and out-of-focus so no model has to
render an interface.

### Prompt A — beat 1 ✅ generated

**Already rendered → `generated/beat1-coldopen.mp4`** (Seedance 2.0, 12s,
1080×1920, 24fps, 4.0 MB, 108 credits). Verified at full resolution: the
monitor is soft blocks only — no legible text, no fabricated logos, no garbled
UI anywhere in the take.

Twelve seconds is coverage, not the cut. Beat 1 needs ~2.5s; the subject scrolls
continuously and sinks lower in the chair across the take, so any window works.
Best 2.5s is around **4.5–7.0s**, where the posture change reads without the
opening settle.

Regenerate with the prompt below if you want a different room, a different
subject, or a warmer grade.

Model: `seedance_2_0` · 9:16 · 12s · 1080p

```
higgsfield generate create seedance_2_0 --aspect_ratio 9:16 --duration 5 --resolution 1080p --generate_audio false --wait --prompt "Over-the-shoulder shot from behind a designer sitting alone at a desk in a dim room at night. The monitor fills the upper third of the frame but is heavily overexposed and thrown out of focus, so no text, icon or interface detail is legible anywhere in the shot — it reads only as a soft bright rectangle with vague rectangular shapes on it. Cool blue monitor light on the back of the head and shoulders, warm practical lamp just out of frame on the right. The person slowly scrolls with one hand, shoulders low, unhurried. Shallow depth of field, the back of the head sharp, the screen and background soft. Static tripod camera, no pan, no tilt, no zoom, no handheld shake. Muted desaturated colour, near-black background, cinematic. No other people, no pets, no visible phone. Nothing on screen is readable in any frame."
```

### Prompt B — beat 5 alternative (optional)

Only if you want beat 5 to move instead of using the still. Feed the real wall

higgsfield generate create seedance_2_0 --start-image ad-assets/resetting-password/stills/flows-wall.png --end-image ad-assets/resetting-password/stills/flows-wall.png --aspect_ratio 16:9 --duration 5 --resolution 1080p --generate_audio false --wait --prompt "Static locked-off screen recording of a dark interface showing a grid of cards. The camera performs one slow push-in and eases back to the exact starting framing. No pan, no tilt, no roll, no shake. > The push-in-and-return wording is deliberate. Seedance ignored the return on

makes the hard cut into the product footage land harder.

bottom-third gradient, or the type will disappear on a phone in daylight.

Regenerate any of it against a different flow:

```bash

```

## Known gap: 6 of 12 screens

`screens/` holds **6** captures, not 12. Logged out, the flow media endpoint
serves the first six and returns `400` for screens 7–12 — the guest paywall.
Beat 4 still works, since the strip pan shows a continuous run of real screens
and the header carries the "12 screens" claim from the product itself.

To ship the full twelve, export a logged-in storage state yourself and re-run:

```bash
npx tsx scripts/generate-ad-assets.ts --flow "Resetting password" --storage state.json
```

I do not handle credentials and will not log in for you. In a browser signed in
to Vitrines, run this in the console and save the output as `state.json`:

```js
copy(JSON.stringify({ origins: [{ origin: location.origin, localStorage:
  Object.entries(localStorage).map(([name, value]) => ({ name, value })) }] }))
```

If cookies carry the session rather than localStorage, use Playwright's
`context.storageState({ path: 'state.json' })` from a signed-in run instead.

## Before you spend on distribution

This ad lands people on a page where clicking any app as a guest opens a blurred
paywall with "Unlock more" six times, and the unlocked screens are the blank
captures. The ad's promise is "see the whole flow"; the guest experience
delivers half of one. Fix the guest preview first — otherwise the spend converts
worse than the creative deserves.
